# MTN-registrering for Home Assistant

Viser medlemsstatistikk fra MTN-registrering, og lar deg åpne døren for besøkende/prøvetimer.

## Installasjon (via HACS)
1. HACS → Integrasjoner → meny (tre prikker) → Egendefinerte repoer
2. Legg til denne repo-URL-en, kategori "Integration"
3. Søk opp "MTN-registrering" i HACS og installer
4. Legg til integrasjonen i HA (Innstillinger → Enheter og tjenester), lim inn API-nøkkelen fra Backend-siden

## Sensorer
- Totalt antall medlemmer
- Innsjekket i dag / siste 48 timer / siste uke
